【双模运行说明】
- 后端模式：用 `python app.pyw` 启动 Flask，所有 /auth /dxf /search 由蓝图处理。
- 前端模式（纯静态托管，如 GitHub Pages）：无后端，runtime.js 自动加载 Pyodide，
  将 pysub/ 与 data 注入虚拟文件系统，由 pysub/browser_server.py 在浏览器内处理上述接口。
- 父页（index.html）只加载“一份”Pyodide，并暴露在 window.__RUNTIME__ 上；
  各 iframe 子页优先复用父页的 Pyodide（不再各自加载），单独打开子页时则自行兜底加载。
- 前端登录为软权限：users.json 随站下发，可被下载，仅作功能分级展示，非真鉴权。

【子路径部署支持】
- 资源与接口探测均基于自动推导的 BASE（如 GitHub Pages 的 /repo/），
  故可部署在子路径下；部署在根路径同样正常。

【打包说明】
打包过程约需几分钟，完成后在 dist/ 生成 LEDDesignTool.exe 及依赖的 .dll/.pyd（单文件夹模式）。
若需真正单一 exe，可在 .spec 中将 EXE 设为 onefile=True，或用：
  pyinstaller --onefile --add-data "index.html;." --add-data "pages;pages" --add-data "static;static" \
    --hidden-import=dxf_generator --hidden-import=profile_engine \
    --hidden-import=ezdxf.bbox --hidden-import=ezdxf.addons.drawing \
    --hidden-import=matplotlib.backends.backend_pdf --hidden-import=matplotlib.pyplot \
    --name=LEDDesignTool --noconsole app.pyw
