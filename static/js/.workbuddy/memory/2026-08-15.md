# 2026-08-15 工作记录

## 修正 led-design-three.js（LED 结构 3D 模型）

修正三处问题（保留全部原有注释与内容）：

1. **重量计算错误（延米重）**
   - `ProfileLib.createMember` 中原重量 = `area * len * 7.85e-9`（偏小 1000 倍）。
   - 改为按截面算延米重：`weightPerMeter = area(mm²) * 0.00785 (kg/m)`，`weight = weightPerMeter * (len/1000) (kg)`，并在 userData 增加 `weightPerMeter`。

2. **模组改为一个个独立实体**
   - 删除原 `if(1==1)` 整块大箱逻辑，改为 plls×plhs 个独立 `BoxGeometry(dycd,dygd,dyhd)` 实体（>200 用 InstancedMesh）。
   - 仅当 `overlayTexture` 存在（上传图片/视频）时隐藏所有独立模组，改由 overlay 平面以单一“面”显示。

3. **材料清单**
   - `updateMaterialList` 统计增加 `weightPerMeter`，表格新增“延米重(kg/m)”列；模组/杆件计数逻辑保持不变（原计数本身正确，重量修正后统计即准确）。

材料清单每行：类型 / 规格 / 延米重 / 数量 / 总长 / 重量。模组数量仍显示在底部。

## 追加：样式迁移 + 不透明 + 材料清单 + 防闪烁

3. **材料清单钢结构统计不全面**

4. **防闪烁**
   - 根因：包边材质 `transparent:true + depthWrite:false` 导致半透明排序闪烁。
