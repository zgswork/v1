根据互联网号码分配机构（IANA）的官方注册表，完整的HTTP状态码列表如下-2。这些状态码根据首位数字被分为五个大类-6。

1xx：信息性状态码
表示请求已被接收，服务器正在继续处理-9。

状态码	含义	说明
100	Continue（继续）	服务器已收到请求头，客户端应继续发送请求体-2。
101	Switching Protocols（切换协议）	服务器根据客户端的请求，正在切换协议-2。
102	Processing（处理中）	服务器已收到并正在处理请求，但尚无响应可用（WebDAV）-2。
103	Early Hints（早期提示）	用于在最终响应前，先返回一些链接头，让浏览器预加载资源-2。
104	Upload Resumption Supported（支持断点续传）	临时注册的状态码，表示服务器支持断点续传-2。
2xx：成功状态码
表示请求已被成功接收、理解并接受-9。

状态码	含义	说明
200	OK（成功）	请求已成功处理-2。
201	Created（已创建）	请求成功，并创建了新的资源-2。
202	Accepted（已接受）	请求已被接受，但尚未处理完成-2。
203	Non-Authoritative Information（非权威信息）	请求成功，但返回的元信息不是来自原始服务器-2。
204	No Content（无内容）	请求成功，但没有返回任何内容-2。
205	Reset Content（重置内容）	请求成功，但要求客户端重置文档视图（如清空表单）-2。
206	Partial Content（部分内容）	服务器成功处理了部分GET请求（用于断点续传或分块下载）-2。
207	Multi-Status（多状态）	返回多条资源的状态信息（WebDAV）-2。
208	Already Reported（已报告）	在一个PROPFIND请求的响应中，用于避免重复列举内部成员（WebDAV）-2。
226	IM Used（已使用IM）	服务器已完成对资源的请求，响应是应用于当前实例的多个操作的结果-2。
3xx：重定向状态码
表示客户端需要采取进一步操作才能完成请求-9。

状态码	含义	说明
300	Multiple Choices（多种选择）	请求的资源有多个可用的响应，用户或浏览器可自行选择-2。
301	Moved Permanently（永久移动）	请求的资源已被永久移动到新URL-2。
302	Found（临时移动）	请求的资源临时从不同的URL响应-2。
303	See Other（查看其它）	应使用GET方法定向到另一个URL来获取响应-2。
304	Not Modified（未修改）	资源未被修改，可使用缓存的版本-2。
305	Use Proxy（使用代理）	被请求的资源必须通过指定的代理才能访问-2。
306	(Unused)（未使用）	原为“Switch Proxy”，现已废弃-2。
307	Temporary Redirect（临时重定向）	资源临时移动，且请求方法和消息主体不得更改-2。
308	Permanent Redirect（永久重定向）	资源永久移动，且请求方法和消息主体不得更改-2。
4xx：客户端错误状态码
表示请求有语法错误或无法被服务器理解-9。

状态码	含义	说明
400	Bad Request（错误请求）	服务器无法理解请求，通常由于语法错误-2。
401	Unauthorized（未授权）	请求需要进行身份验证-2。
402	Payment Required（需要付款）	保留状态码，未来可能用于数字支付系统-2。
403	Forbidden（禁止）	服务器理解请求，但拒绝执行-2。
404	Not Found（未找到）	服务器无法找到请求的资源-2。
405	Method Not Allowed（方法不允许）	请求方法不被服务器支持-2。
406	Not Acceptable（不可接受）	服务器无法根据客户端请求的内容特性完成请求-2。
407	Proxy Authentication Required（需要代理认证）	客户端必须先通过代理的认证-2。
408	Request Timeout（请求超时）	服务器等待客户端发送请求的时间过长-2。
409	Conflict（冲突）	请求与服务器当前状态发生冲突-2。
410	Gone（已消失）	请求的资源已被永久删除-2。
411	Length Required（需要长度）	请求头中缺少Content-Length字段-2。
412	Precondition Failed（前置条件失败）	请求头中的某些前置条件未通过服务器验证-2。
413	Content Too Large（内容过大）	请求体太大，服务器无法处理-2。
414	URI Too Long（URI过长）	请求的URI太长，服务器无法处理-2。
415	Unsupported Media Type（不支持的媒体类型）	请求的格式不被服务器支持-2。
416	Range Not Satisfiable（范围无法满足）	请求的范围无效或无法满足-2。
417	Expectation Failed（期望失败）	服务器无法满足请求头Expect字段指定的要求-9。
418	I'm a Teapot（我是茶壶）	愚人节玩笑，表示服务器拒绝煮咖啡，因为它是个茶壶-9。
421	Misdirected Request（误定向请求）	请求被发送到一个无法产生响应的服务器-9。
422	Unprocessable Entity（无法处理的实体）	请求格式正确，但语义错误，无法处理-9。
423	Locked（已锁定）	请求的资源被锁定（WebDAV）-9。
424	Failed Dependency（依赖失败）	请求失败，因为之前的某个请求失败（WebDAV）-9。
425	Too Early（太早）	服务器拒绝处理可能被重放的请求-9。
426	Upgrade Required（需要升级）	客户端应切换到其他协议-9。
428	Precondition Required（需要前置条件）	服务器要求请求必须包含某些条件头-9。
429	Too Many Requests（请求过多）	用户在给定时间内发送了太多请求（限流）-9。
431	Request Header Fields Too Large（请求头字段过大）	请求头太大，服务器无法处理-9。
451	Unavailable For Legal Reasons（因法律原因不可用）	因法律原因，服务器无法提供该资源-9。
5xx：服务器错误状态码
表示服务器在处理请求时发生了内部错误-9。

状态码	含义	说明
500	Internal Server Error（服务器内部错误）	服务器遇到了一个未曾预料的情况，无法完成请求-2。
501	Not Implemented（未实现）	服务器不支持实现请求所需的功能-2。
502	Bad Gateway（网关错误）	服务器作为网关或代理，从上游服务器收到了无效响应-2。
503	Service Unavailable（服务不可用）	服务器当前无法处理请求（超载或停机维护）-2。
504	Gateway Timeout（网关超时）	服务器作为网关或代理，未能及时从上游服务器收到响应-2。
505	HTTP Version Not Supported（HTTP版本不支持）	服务器不支持请求中使用的HTTP协议版本-2。
506	Variant Also Negotiates（变体也协商）	服务器存在内部配置错误-2。
507	Insufficient Storage（存储空间不足）	服务器无法存储完成请求所需的内容（WebDAV）-2。
508	Loop Detected（检测到循环）	服务器在处理请求时检测到无限循环（WebDAV）-2。
510	Not Extended（未扩展）	请求需要进一步扩展才能完成-2。
511	Network Authentication Required（需要网络认证）	客户端需进行网络认证才能访问-2。
