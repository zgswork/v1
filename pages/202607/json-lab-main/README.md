# 🔬 JSON Lab

**本地离线 JSON 格式化、校验与树状浏览工具。单个 HTML 文件，零外部依赖。**

## 一句话

粘贴一段 JSON 进去，就能立刻格式化、校验语法错误、用树状结构展开浏览。
全程在浏览器本地运行，不需要联网，不上传任何数据。

打开就能用：

```bash
double-click projects/json-lab/index.html
```

## 功能

- **格式化**（Pretty-Print）：把压缩的 JSON 展开成可读的缩进格式
- **校验**（Validate）：语法错误时直接标出位置和原因
- **树状浏览**（Tree View）：展开/折叠节点，数字、字符串、布尔值、null 用不同颜色区分
- **压缩**（Minify）：把格式化后的 JSON 压回一行
- **复制结果**：一键复制格式化/压缩后的内容
- **拖拽文件**：直接把 `.json` 文件拖进页面加载
- **本地存储**：关闭页面再打开，上次的内容还在
- **深色主题**：护眼深色界面

## 为什么做这个

每个开发者都经常需要看 JSON：API 返回、配置文件、日志片段。在线工具有广告和追踪器，
而且上传数据时有隐私顾虑。JSON Lab 全部在浏览器本地运行，一个 HTML 文件就能带走，
U 盘里存一份到哪都能用。

适合用在：
- 调试 API 返回时快速格式化查看
- 编辑配置文件时检查语法
- 展示数据给同事时用树状视图
- 断网环境或内网开发机

## 怎么用

```bash
# 方式一：双击打开（最简单）
double-click projects/json-lab/index.html

# 方式二：本地 HTTP 服务
cd projects/json-lab
python3 -m http.server 8765
# 浏览器打开 http://127.0.0.1:8765
```

打开后：
1. 左侧输入框里已经有一段样例 JSON
2. 点击「格式化」按钮，右侧立刻展示格式化结果
3. 切换到「树状视图」标签，按层级展开查看
4. 点「复制」按钮把格式化后的 JSON 复制到剪贴板

## 技术说明

- 纯前端，单 HTML 文件（HTML + CSS + JavaScript 全部内联）
- 使用浏览器原生 `JSON.parse` / `JSON.stringify` 做核心格式化
- 树状视图递归渲染，支持深色主题高亮
- localStorage 自动保存上次内容
- 兼容 Chrome / Firefox / Safari / Edge
