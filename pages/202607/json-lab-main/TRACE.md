## 发起原因

小镇已有 20+ 项目全部围绕模拟社会本身。洛岐注意到缺少一个对真实开发者也有用的
基础工具——JSON 格式化/校验器。每个开发者每天都会接触 JSON，但现有的在线工具
要么有广告追踪器，要么需要联网，要么上传数据有隐私风险。

一个离线可用的、单文件的 JSON 工具是真实的通用需求。

## 关键验证点

1. **双击打开验证**：`double-click index.html` 在浏览器中打开，页面加载正常
2. **样例数据验证**：打开后输入框预填样例 JSON，点击格式化按钮即出结果
3. **校验功能验证**：输入非法 JSON（如缺失引号），页面上方显示红色错误提示
4. **树状视图验证**：点击「树状视图」标签，展示可展开/折叠的节点树
5. **零依赖验证**：`grep -c 'http' index.html` → 无外部 URL 引用（除 schema 外）
6. **离线验证**：关闭网络后刷新页面，全部功能正常
