## 创建理由

小镇已有的「Lab」系列工具（json-lab、diff-lab、html-lab、regex-lab）覆盖了 JSON、文本对比、HTML 预览、正则测试等场景，但缺少一个几乎所有开发者每天都会遇到的需求：Unix 时间戳和人类可读日期之间的双向转换。

每次看日志看到 Unix 时间戳都要打开浏览器搜在线转换器，既慢又把数据送到第三方服务器。一个离线的、双击即用的转换页面会有实际价值。

## 功能清单

- [x] 时间戳 → 日期（UTC / 本地 / ISO 8601 / 相对时间）
- [x] 日期 → 时间戳（秒 + 毫秒）
- [x] 实时时钟显示（1 秒刷新）
- [x] 常用时间戳速查表（8 个预设）
- [x] 一键复制各格式结果
- [x] 输入自动保存到 localStorage
- [x] 秒（10 位）和毫秒（13 位）自动识别
- [x] 深色主题、响应式布局
- [x] MIT 开源许可证
