U盘安装系统教程

准备工作

1. 一个容量至少8GB的U盘（建议使用USB3.0及以上接口的U盘）

2. 系统镜像文件（ISO格式）

3. U盘启动盘制作工具

制作U盘启动盘

1. 下载并安装U盘启动盘制作工具（推荐工具见下方）

2. 插入U盘（注意备份U盘数据，制作过程会格式化U盘）

3. 打开制作工具，选择系统镜像文件

4. 选择目标U盘，点击"开始制作"

5. 等待制作完成（通常需要10-30分钟，取决于U盘速度和镜像大小）

设置BIOS/UEFI启动顺序

1. 重启电脑，在开机时按下特定键进入BIOS/UEFI设置（通常是Del、F2、F12等，因主板而异）

2. 找到"Boot"或"启动"选项

3. 将U盘设为第一启动项

4. 保存设置并退出（通常是F10）

安装系统

1. 电脑将从U盘启动，进入安装界面

2. 选择语言、时间和键盘输入法，点击"下一步"

3. 点击"现在安装"

4. 输入产品密钥（如果有，也可跳过）

5. 选择要安装的系统版本

6. 接受许可条款

7. 选择"自定义：仅安装Windows（高级）"

8. 选择安装位置（建议格式化目标分区）

9. 等待安装完成，电脑会自动重启多次

10. 完成初始设置（用户名、密码等）

注意事项

• 安装前请备份重要数据

• 确保电脑电量充足或连接电源

• 安装过程中不要强制关机

• 如果遇到驱动问题，请参考下方的驱动安装部分

硬盘安装系统教程（无U盘）

准备工作

1. 系统镜像文件（ISO格式）

2. 解压工具（如WinRAR、7-Zip）

3. NT6 HDD Installer工具（适用于老旧系统）

4. 确保有一个至少20GB的空闲分区

方法一：直接解压安装（适用于Windows 10/11）

1. 右键点击ISO文件，选择"装载"（或使用解压工具解压到文件夹）

2. 进入解压后的文件夹，双击运行"setup.exe"

3. 选择"不是现在"跳过密钥输入

4. 接受许可条款

5. 选择"保留个人文件和应用"或"仅保留个人文件"（或"无"全新安装）

6. 点击"安装"并等待完成

方法二：使用NT6 HDD Installer（适用于Windows 7）

1. 将系统ISO解压到非系统盘的根目录（如D:\）

2. 下载并运行NT6 HDD Installer

3. 选择模式（通常选择模式1或2）

4. 点击"安装"

5. 重启电脑，在启动菜单中选择NT6 HDD Installer

6. 按照正常安装流程进行安装

注意事项

• 硬盘安装法风险较高，建议仅在U盘不可用时使用

• 安装前务必备份重要数据

• 可能需要手动修复启动引导

系统激活指南

正版激活方法

1. 购买正版密钥：通过微软官网或授权经销商购买

2. 设置 → 更新和安全 → 激活 → 更改产品密钥

3. 输入购买的正版密钥

4. 等待激活完成

数字许可证激活（适用于重装）

1. 确保之前已使用正版密钥激活过系统

2. 重装相同版本系统后，连接互联网

3. 系统会自动识别硬件并激活

关于KMS激活的说明

KMS（密钥管理服务）是企业批量激活方案，个人使用可能涉及版权问题。以下信息仅用于教育目的：

1. 以管理员身份运行CMD

2. 输入以下命令（以Windows 10为例）：

slmgr /ipk W269N-WFGWX-YVC9B-4J6C9-T83GX
slmgr /skms kms.03k.org
slmgr /ato

• KMS激活通常需要180天重新激活一次

• 微软官方不推荐此方法用于个人用户

推荐工具：Microsoft Activation Scripts (MAS)

开源激活脚本，支持Windows和Office的HWID和KMS38激活

优点：开源透明，无恶意软件，支持永久激活

驱动安装指南

自动安装驱动方法

1. Windows Update：系统会自动安装大部分驱动

2. 使用驱动管理软件（推荐如下）

3. 品牌电脑可使用官方支持助手

手动安装驱动方法

1. 确定硬件型号（通过设备管理器或硬件检测工具）

2. 访问硬件制造商官网下载对应驱动

3. 运行安装程序或手动更新驱动

数据恢复指南

数据恢复基本原则

1. 发现数据丢失后立即停止使用该存储设备

2. 不要将恢复的数据保存到原位置

3. 优先尝试恢复重要文件

4. 物理损坏建议寻求专业帮助

常见数据恢复场景

误删除文件：使用Recuva等工具快速恢复

格式化恢复：需要深度扫描，如EaseUS Data Recovery

分区丢失：使用DiskGenius等工具扫描分区表

系统崩溃：通过PE系统访问磁盘复制数据
