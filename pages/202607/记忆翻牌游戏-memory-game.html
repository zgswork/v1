游戏教程

基本玩法

记忆翻牌游戏的目标是在尽可能短的时间或最少的尝试次数内，找到所有匹配的卡片对。

  • 选择你喜欢的难度、主题和模式。
  • 点击“开始游戏”按钮。
  • 每次点击翻开一张卡片。连续翻开两张卡片。
  • 如果两张卡片的图案相同，它们就会匹配成功并保持翻开状态。
  • 如果图案不同，它们会在短暂显示后翻回去。
  • 继续翻牌，直到找到所有匹配的卡片对。

游戏模式

  • 经典模式: 没有时间和步数限制。专注于用最少的尝试次数和时间完成游戏。得分根据用时和尝试次数计算。
  • 计时挑战: 你需要在规定的时间内找到所有匹配的卡片。时间耗尽则游戏结束。得分根据剩余时间计算。
  • 限步挑战: 你需要在规定的尝试次数（每次翻开两张算一次）内找到所有匹配的卡片。步数用尽则游戏结束。
  • 渐进难度: 从简单难度 (4x4) 开始，成功通关后自动进入下一难度 (6x6)，再到困难难度 (8x8)。

提示功能

游戏中遇到困难时，可以点击“提示”按钮。系统会为你短暂显示一对尚未匹配的卡片。每次游戏有次数限制（默认为3次），使用提示会增加一次尝试次数。

音效开关

你可以通过勾选/取消勾选“音效”复选框来打开或关闭游戏音效。

排行榜

游戏结束后，如果你的得分足够高，将会被记录在页面底部的历史排行榜中（最多显示前10名）。
