# 测试场景

## 项目概述

Code Navigator 是一个完全离线的、纯前端实现的 Web 工具，用于上传项目 ZIP 文件后，帮助开发者快速导航和理解大型代码库。

## 测试资源

在 `tests/` 目录下提供了以下测试资源：
- `sample_small.zip`: 小型项目（<10 文件，多语言，包含 JS 和 Python 等）

## 测试场景

### 场景 1: 基本功能测试 - 文件上传与目录解析

**测试步骤：**
1. 打开 Code Navigator 工具
2. 点击 "上传 ZIP" 按钮，选择 `tests/sample_small.zip` 文件
3. 等待文件解析完成

**预期结果：**
- 文件上传成功，显示解析进度条
- 解析完成后，左侧面板显示完整的目录树结构
- 目录树包含以下结构：
  - js/main.js
  - python/main.py
  - java/Main.java
  - README.md
- 支持展开/折叠文件夹功能
- 默认忽略目录（如 node_modules、dist 等）功能正常

### 场景 2: 代码查看与语法高亮测试

**测试步骤：**
1. 在左侧目录树中点击 `js/main.js` 文件
2. 查看右侧代码查看器中的内容
3. 重复步骤 1-2，分别查看 `python/main.py` 和 `java/Main.java` 文件

**预期结果：**
- 点击文件后，右侧面板显示该文件的完整内容
- 显示行号，行号从 1 开始
- 不同语言的代码都有正确的语法高亮：
  - JavaScript: 关键词（function, class, const 等）、字符串、注释、函数名等都有不同颜色
  - Python: 关键词（def, class, if 等）、字符串、注释、函数名等都有不同颜色
  - Java: 关键词（public, class, static 等）、字符串、注释、函数名等都有不同颜色
- 代码折叠功能正常，支持函数/类/块级折叠

### 场景 3: 全局符号搜索测试

**测试步骤：**
1. 在顶部搜索框中输入 "Calculator"
2. 查看搜索结果
3. 点击搜索结果中的任一项
4. 重复步骤 1-3，分别搜索 "fibonacci"、"greet"、"DataProcessor"

**预期结果：**
- 搜索框支持模糊搜索
- 搜索结果显示包含 "Calculator" 符号的所有文件：
  - js/main.js: 第 7 行的 class Calculator
  - java/Main.java: 第 24 行的 class Calculator
- 搜索结果显示 "符号名 - 文件路径:行号" 格式
- 点击搜索结果中的任一项，能够跳转到对应文件并高亮显示该行
- 其他搜索词也能正确显示所有匹配的符号定义

### 场景 4: 书签与最近打开历史测试

**测试步骤：**
1. 打开任意文件（如 `js/main.js`）
2. 点击代码查看器右上角的星形图标，添加书签
3. 打开另一个文件（如 `python/main.py`）
4. 查看左侧面板的 "最近打开" 列表
5. 刷新页面
6. 查看左侧面板的 "书签" 和 "最近打开" 列表

**预期结果：**
- 添加书签后，星形图标变为实心，显示为黄色
- "最近打开" 列表显示最近打开的文件，最多 5 个
- 刷新页面后，书签和最近打开历史仍然保留
- 能够通过点击书签列表中的条目快速打开对应文件
- 能够通过点击最近打开列表中的条目快速打开对应文件

### 场景 5: 用户界面与主题切换测试

**测试步骤：**
1. 查看界面布局，确认是否符合经典 IDE 布局
2. 点击顶部工具栏的 "暗黑模式" 按钮
3. 再次点击 "亮色模式" 按钮
4. 查看底部状态栏的信息
5. 测试键盘快捷键：
   - Ctrl/Cmd + F: 聚焦搜索框
   - Ctrl/Cmd + B: 切换书签
   - ESC: 关闭搜索结果

**预期结果：**
- 界面布局符合经典 IDE 布局：
  - 顶部：工具栏（上传 ZIP、搜索框、清除数据按钮、主题切换）
  - 左侧面板：书签区 + 最近文件 + 文件树
  - 右侧主区：代码查看
  - 底部状态栏：当前文件路径、行/列位置、语言、文件大小
- 主题切换功能正常，能够在暗黑/亮色主题之间切换
- 底部状态栏显示当前打开文件的正确信息：
  - 文件路径
  - 行/列位置
  - 语言类型
  - 文件大小
- 键盘快捷键功能正常：
  - Ctrl/Cmd + F: 搜索框获得焦点
  - Ctrl/Cmd + B: 当前文件的书签状态切换
  - ESC: 关闭搜索结果下拉框

### 场景 6: 大文件优化测试

**测试步骤：**
1. 准备一个较大的代码文件（建议 1000+ 行）
2. 将该文件添加到一个 ZIP 文件中
3. 上传该 ZIP 文件到 Code Navigator 工具中
4. 打开这个大文件
5. 查看代码查看器的性能和显示效果

**预期结果：**
- 大文件能够正常加载和显示
- 行号正确显示，不会出现性能问题
- 代码折叠功能正常，能够折叠/展开大的代码块
- 滚动浏览大文件时性能良好，没有明显的卡顿
- 语法高亮在大文件中仍然正确显示

## 测试环境要求

- 现代 Web 浏览器（建议使用 Chrome、Firefox、Safari 或 Edge 的最新版本）
- JavaScript 必须启用
- 不需要网络连接（完全离线使用）
- 建议使用屏幕分辨率 1024x768 或更高
