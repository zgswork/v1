# Code Navigator - 离线代码导航工具

Code Navigator 是一个完全离线的、纯前端实现的 Web 工具，用于上传项目 ZIP 文件后，帮助开发者快速导航和理解大型代码库。所有解析和渲染操作都在浏览器中完成，无需服务器支持。

## 核心功能

### 1. ZIP 文件上传与目录解析
- 支持拖拽或文件选择上传 ZIP 文件
- 使用 JSZip 异步解析文件，不阻塞 UI
- 构建完整的目录树结构，支持展开/折叠文件夹
- 识别常见语言文件扩展名
- 默认忽略目录：node_modules、dist、build、.git、__pycache__、vendor 等
- 解析进度条显示
- 支持最大 50MB 的 ZIP 文件

### 2. 左侧文件树 + 右侧代码查看
- 左侧：树形文件浏览器，支持键盘导航和 Enter 键打开文件
- 右侧：代码查看面板，纯 CSS 实现语法高亮
- 支持常见语言的高亮规则（关键词、字符串、注释、数字、函数名等）
- 行号显示
- 代码折叠（支持函数/类/块级折叠）
- 大文件优化

### 3. 全局符号搜索
- 顶部搜索框，支持模糊搜索
- 搜索范围：全部文件
- 符号类型：函数名、类名、变量名、常量名
- 简单符号提取规则（基于正则表达式）
- 搜索结果显示格式："符号名 - 文件路径:行号"
- 点击搜索结果可跳转到对应文件并高亮该行

### 4. 书签与最近打开历史
- 书签功能：为常用文件添加星标
- 最近打开：自动记录最近 5 个打开的文件
- 数据持久化：使用 localStorage 保存，跨会话保留

### 5. 用户界面
- 经典 IDE 布局：
  - 顶部：工具栏（上传 ZIP、搜索框、清除数据、主题切换）
  - 左侧面板：书签区 + 最近文件 + 文件树
  - 右侧主区：代码查看
  - 底部状态栏：当前文件路径、行/列位置、语言、文件大小
- 暗黑/亮色主题切换（默认跟随系统）
- 键盘快捷键支持

## 技术栈

- 纯 HTML + CSS + JavaScript 实现
- 无需服务器，完全离线使用
- 使用 JSZip 库解析 ZIP 文件
- 使用 Font Awesome 图标库
- 纯 CSS 实现代码高亮，无需额外 JavaScript 库

## 使用方法

1. 克隆或下载此项目到本地
2. 直接在浏览器中打开 `index.html` 文件
3. 点击 "上传 ZIP" 按钮，选择要分析的项目 ZIP 文件
4. 等待文件解析完成后，即可在左侧文件树中浏览项目结构
5. 点击任意文件即可在右侧代码查看器中查看代码内容
6. 使用顶部搜索框可以搜索项目中的函数、类、变量等符号
7. 使用书签功能可以快速访问常用文件

## 测试

项目中包含 `tests/` 文件夹，提供以下测试资源：
- `sample_small.zip`: 小型测试项目（包含 JS、Python、Java 代码）
- `test_scenarios.md`: 详细的测试场景说明

## 注意事项

- 所有操作都在浏览器中完成，不会向服务器发送任何数据
- 解析大文件可能会消耗较多浏览器内存，建议分批次分析大型项目
- 不支持密码保护的 ZIP 文件
- 符号提取基于正则表达式，可能不是 100% 准确
