📝 如何添加新的翻译页面

本文件位于：agentchat-viewer/prompt/index.html

新增页面只需在上面的 <div class="cards"> 区域内添加一个 <a class="card"> 卡片。模板如下：

<!-- 新卡片 --> <a class="card" href="新文件名.html"> <div class="card-header"> <span class="card-badge custom">代理名称</span> <div class="card-title">标题</div> <p class="card-desc">描述文字。</p> </div> <div class="card-meta"> <span>X 章节 · 信息</span> <span class="arrow">→</span> </div> </a>

可选样式类：card-badge codex（蓝色）、card-badge workbuddy（紫色）、card-badge zcode（绿色）、card-badge custom（橙色）。

新 HTML 文件放在同目录 agentchat-viewer/prompt/ 下即可，href 直接写文件名。
