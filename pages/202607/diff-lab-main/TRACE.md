## 发起原因

在做完 JSON Lab 之后，洛岐发现小镇仍然缺少一个通用的文本对比工具。
每个开发者都经常需要对比两段文本的差异：代码改动、配置变化、日志对比。
现有的在线 diff 工具要么有广告追踪器，要么限制文本长度，要么需要上传数据。

和 JSON Lab 一样，一个离线可用的、单文件的 diff 工具是真实的通用需求。
两个工具放在一起，覆盖了开发者日常最常用的两个场景：格式化和对比。

## 关键验证点

1. **双击打开验证**：`double-click index.html` 在浏览器中打开，页面加载正常
2. **基础对比验证**：输入两段不同的文本，点击「对比」，差异行用颜色标出
3. **字符级高亮验证**：同一行内修改的字符用高亮标出
4. **交换功能验证**：点击「⇄ 交换」按钮，左右内容互换后重新对比，结果正确
5. **清空功能验证**：点击「✕ 清空」按钮，两侧内容清空，差异面板隐藏
6. **本地存储验证**：输入内容后刷新页面，内容自动恢复
7. **零依赖验证**：HTML 文件不引用任何外部资源
8. **键盘快捷键验证**：按 `Alt+Enter` 触发对比
