# 🧪 Diff Lab · 文本对比工具

**粘贴两段文本，立刻看到差异。单 HTML 文件，零外部依赖，离线可用。**

## 一句话

把两段文本分别贴在左右两侧，点一下「对比」，差异行立刻高亮标出——
新增的行绿色、删除的行红色、修改的行黄色，具体的字符级变化也会标出来。

双击就能用：

```bash
double-click projects/diff-lab/index.html
```

## 功能

- **逐行对比**：左侧原文、右侧新文，差异行用颜色标出
- **字符级高亮**：同一行内具体改了哪个词，用更深的颜色标出来
- **三种操作类型**：新增（绿）、删除（红）、修改（黄），一目了然
- **行号对照**：左右两侧的行号独立编号，修改行对齐显示
- **一键交换**：点击「⇄ 交换」按钮，左右内容互换，方便切换视角
- **清空重置**：一键清空两侧内容
- **键盘快捷键**：`Alt+Enter` 快速触发对比
- **本地存储**：关闭页面再打开，上次的内容还在
- **深色主题**：护眼深色界面，和 JSON Lab 风格一致

## 什么时候用

- 对比两份配置文件找不同
- 核对 API 返回结果的变化
- 比较两段代码的改动
- 检查日志输出差异
- 复审自己改过的文档

## 和同类工具有什么区别

大多数在线 diff 工具需要上传数据、有广告、或限制文本长度。
Diff Lab 全部在浏览器本地运行，不上传任何数据，不限文本长度，
一个 HTML 文件就能带走，U 盘里存一份到哪都能用。

## 怎么用

### 打开页面

```bash
# 方式一：双击文件
double-click projects/diff-lab/index.html

# 方式二：从终端打开
open projects/diff-lab/index.html  # macOS
xdg-open projects/diff-lab/index.html  # Linux
```

### 使用步骤

1. 在左侧文本框粘贴「原文本」
2. 在右侧文本框粘贴「新文本」
3. 点击「对比」按钮（或按 `Alt+Enter`）
4. 差异行自动用颜色标出，点击任意差异行可以查看字符级变化

### 示例

可以试试把这两段分别贴到左右两侧：

**左侧（原文）：**
```
def hello(name):
    print("Hello, " + name)
    return True
```

**右侧（新文）：**
```
def greet(name):
    print(f"Hello, {name}")
    return True
```

点击「对比」，就能看到函数名从 `hello` 改成了 `greet`，字符串拼接改成了 f-string。
