现代浏览器 Web API 能力评估

在单页（HTML）环境下对主流 Web API 的可用性进行系统性检测，结果反映 API 表面能力的暴露状态，不涉及权限弹窗或设备交互。

单页环境的能力与约束

  • 本地文件： 若支持 File System Access API，可对用户明确选择的文件进行读写与持久化保存。
  • 外设与算力： 可通过 Web Bluetooth、WebUSB、Web Serial 进行外设通信，并利用 WebGL/WebGPU 访问图形硬件算力。
  • 离线与缓存： 依托 Service Worker 实现缓存与请求拦截，从而支持离线运行；需 HTTPS 或 localhost。
  • 安全与权限： 能力存在不等于授权已授予。摄像头、麦克风、文件读写等操作需要用户同意，且多数 API 仅在安全上下文下可用（file:// 常受限）。
