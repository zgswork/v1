## 1. 产品概述

### 1.1 产品定位
**Format** 是一款面向个人用户、行政人员及文字工作者的**本地化、轻量化文本样式排版工具**。它旨在解决纯文本或格式混乱文档转换为标准 Word (.docx) 格式时的繁琐排版问题。通过“输入-配置-预览-导出”的一站式流程，实现零门槛的专业文档格式化。

### 1.2 核心价值
-   **隐私安全**：纯本地运行，无后端服务器，不联网，不留存任何用户数据。
-   **开箱即用**：免安装，单文件启动或浏览器直接打开，跨平台兼容 Windows/macOS。
-   **高效标准化**：通过模板系统，将复杂的排版参数一键应用，保证输出文档符合公文/论文/报告规范。
-   **所见即所得**：实时预览机制，避免反复试错。

### 1.3 目标用户
-   需要快速整理会议纪要、草稿的职场人士。
-   对 Word 样式功能不熟悉，但需提交规范文档的学生/研究员。
-   注重数据隐私，不愿使用在线转换工具的用户。

## 2. 功能详细设计

### 2.1 模块一：内容输入区（左侧面板）

| 功能点 | 详细描述 | 约束/规则 |
| :--- | :--- | :--- |
| 文本粘贴 | 提供多行文本框，支持 Ctrl+V / Cmd+V 粘贴 | 上限 20,000 字符；超出自动截断并 Toast 提示；关闭软件时自动清空缓冲区 |
| 文件导入 | 支持拖拽或点击选择文件 | 支持 .txt, .md, .docx 格式；支持多选批量导入 |
| 批量队列 | 显示待处理文件列表 | 显示文件名、大小、状态（等待/处理中/完成/失败）；支持移除单项、清空队列 |
| 内容清洗 | 自动去除多余空行、全角转半角（可选） | 提供开关，默认开启基础清洗；清洗操作在内存中完成，不修改源文件 |

### 2.2 模块二：样式参数配置区（中间面板）

采用分组折叠面板设计，避免参数过多导致视觉疲劳。所有参数修改后自动触发右侧预览刷新（防抖 300ms）。

#### 2.2.1 页面设置
-   **纸张大小**：A4 / Letter / B5 / 自定义（宽×高 mm）
-   **页边距**：上/下/左/右（单位：mm，步进 0.5）
-   **页脚设置**：页脚距底边距离（mm）；页码对齐方式（左/中/右）；页码字体/字号

#### 2.2.2 标题样式
-   **主标题**：字体（下拉选择+手动输入）、字号、行距（固定值/倍数，单位：磅）、对齐方式、段前段后间距
-   **副标题**：同上参数独立配置
-   **正文标题层级 (H1-H4)**：每级独立配置字体、字号、行距、缩进、编号格式（如 1. / 1.1 / (1)）

#### 2.2.3 正文样式
-   **基础属性**：字体、字号、行距（固定值磅数）、首行缩进（字符数/mm）、左右缩进
-   **数字字母格式化**：
    -   开关：是否自动区分中西文字体
    -   西文/数字专用字体（如 Times New Roman）
    -   西文/数字专用字号（可与中文不同）

#### 2.2.4 高级选项
-   **自动生成目录**：开关；目录标题文本；包含层级（1-4级）
-   **大纲级别映射**：自动识别 Markdown # 号或正则匹配标题
-   **分页控制**：标题前自动分页（可选）

### 2.3 模块三：模板管理系统

-   **保存模板**：将当前所有参数序列化为 JSON 文件。
    -   命名规则：`format_template_[name]_[timestamp].json`
    -   存储位置：软件同级目录 `/templates/` 文件夹
-   **加载模板**：
    -   内置默认模板（公文标准、学术论文、简洁报告）
    -   自动读取 `/templates/` 下所有合法 JSON 文件
    -   支持导入外部 JSON 文件
-   **模板编辑**：加载后可编辑并另存为新模板，支持覆盖原模板
-   **安全校验**：加载模板时仅读取白名单字段，非法字段自动忽略并记录日志

### 2.4 模块四：实时预览与输出（右侧面板）

-   **预览渲染**：
    -   根据当前参数实时生成 docx 样式快照
    -   支持缩放滑块（50%-200%）
    -   支持翻页导航
    -   批量模式下可切换预览不同文件的排版效果
-   **确认输出**：
    -   预览区底部设置“确认导出”按钮，用户确认样式无误后方可导出
    -   单文件：弹出系统保存对话框
    -   批量文件：选择输出文件夹，自动命名为 `[原文件名]_formatted.docx`
-   **异常提示**：预览生成失败时显示错误摘要，不影响参数调整

### 3.2 视觉风格
-   **配色**：浅灰白背景 (#F8F9FA) + 深灰文字 (#2C3E50) + 品牌蓝强调色 (#3498DB)
-   **控件**：圆角卡片式分组，输入框紧凑排列，减少留白浪费
-   **反馈**：所有操作均有微动效；耗时操作显示进度条；错误信息使用非阻塞 Toast
-   **响应式**：窗口最小宽度 1024px，低于该宽度时隐藏预览区，提供“预览”浮动按钮

## 4. 非功能性需求与安全设计

### 4.1 隐私与安全（核心红线）
-   **零网络请求**：运行时不得发起任何外部网络请求，包括字体加载、统计上报、更新检查等。
-   **内存清理**：
    -   关闭应用时，主动覆写内存中的文本缓冲区
    -   临时预览文件存放在系统 TEMP 目录，退出时立即删除
-   **无数据库**：所有持久化数据仅限 `/templates/` 下的 JSON 文件和 `/logs/` 下的日志文件
-   **权限最小化**：仅申请文件读写（限定工作目录）和系统对话框权限，不申请剪贴板监听、开机启动等额外权限

### 4.2 日志与调试
-   **日志分级**：INFO / WARN / ERROR / DEBUG
-   **日志位置**：软件同级目录 `/logs/format_YYYYMMDD.log`
-   **日志内容**：
    -   启动/退出时间
    -   模板加载/保存事件
    -   文件处理成功/失败详情（不含文件内容，仅记录文件名、大小、耗时）
    -   异常堆栈信息
-   **用户入口**：底部状态栏提供“打开日志文件夹”快捷按钮
-   **日志轮转**：单文件超过 5MB 自动归档，最多保留 7 天日志

### 4.3 性能指标
-   **启动时间**：< 2秒（冷启动）
-   **单文件处理**：10,000 字以内 < 1秒
-   **批量处理**：100个文件队列不卡顿，UI 响应延迟 < 100ms
-   **内存占用**：空闲 < 80MB，峰值 < 300MB

### 4.4 异常处理与边界情况
-   **字体缺失**：预览区顶部增加黄色警示条：“检测到缺少字体 [XXX]，已替换为 [SimSun]，导出结果可能不一致”
-   **大文件保护**：超过 20,000 字符的粘贴内容自动截断；超过 10MB 的文件导入时弹出确认提示
-   **批量中断恢复**：记录处理进度到临时文件；重启后可选择“继续上次任务”
-   **目录更新提示**：导出文档首页插入灰色提示文本：“请在 Word 中右键目录选择‘更新域’以刷新页码”，打印时自动隐藏
-   **macOS 权限引导**：首次运行时检测文件访问权限，未授权时禁用文件导入并显示系统级授权引导
-   **模板版本兼容**：JSON 模板包含 version 字段；加载旧版模板时自动填充新增参数的默认值，不报错
