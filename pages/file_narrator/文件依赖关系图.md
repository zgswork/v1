## 维护链路（改哪里会影响什么）

| 你要做的事 | 动的文件 | 自动波及 |
|---|---|---|
| 加 / 删 / 换内容文件 | `file/` | 无（页面按 `narration_data.js` 的 url/src 找文件） |
| 加 / 改解说条目、触点、文案 | `js/narration_data.js` | 文案变了 → 双击 `tools/gen_voice_oneclick.pyw` 重生成对应 mp3 |
| 调整两级筛选（开关 / 名称 / 分类） | `js/narration_data.js` 的 `cascade` 与条目 `cat` / `sub` | 筛选选项自动按条目去重生成，无需改页面 |
| 重新生成离线语音 | 双击 `tools/gen_voice_oneclick.pyw` | 只重做缺失 / 文案指纹变动的条目 |
| 改样式 / 改交互逻辑 | `index.html` 对应内联段 | 无 |
| 换 PDF.js 版本 | `js/lib/pdf.min.js` + `pdf.worker.min.js`（必须成对） | 无 |
| 目录改名 / 资源增删 | 同步更新 htmlstars 根 `verify_mount.py` 的 `RES` 清单 | `menus.json` 的 `page` 路径 |

**注意**：`index.html` 必须经 http 服务打开（`file://` 直开时 Chrome 拦截本地文件读取）；
`css` 层叠兜底 `[hidden]{display:none !important}` 内联在样式段中，勿删（否则"加载失败"遮罩常驻）；
改 `narration_data.js` 文案后不重新生成音频 → 音频与页面文字不一致。
