# 森系微光皮肤

## 概述

森系微光是一款自然治愈风格的皮肤主题，融合轻复古与极简质感，以植物元素为点缀，营造柔和、松弛且充满呼吸感的视觉体验。

## 设计理念

- **自然色调**：采用薄荷绿、浅卡其、米白等自然色彩，营造舒适放松的视觉感受
- **柔和质感**：使用圆润边角、柔和阴影和细腻过渡，增强界面的亲和力
- **呼吸感设计**：合理的留白和空间布局，让界面更加通透自然
- **微光点缀**：通过微妙的渐变和高光效果，增加界面的层次感和精致度

## 颜色方案

- **主色调**：薄荷绿 (#A3E635)
- **背景色**：米白色 (#FAFAFA)、浅卡其 (#F5F0E1)
- **强调色**：珊瑚粉 (#FCA5A5)
- **文字色**：深灰 (#333333)、中灰 (#6B7280)、浅灰 (#9CA3AF)
- **边框色**：浅灰 (#E5E7EB)、极浅灰 (#F3F4F6)

## 使用方法

1. 将 `forest_glow` 文件夹复制到 `skins` 目录下
2. 在皮肤选择器中选择"森系微光"
3. 刷新页面即可应用新皮肤

## 自定义调整

皮肤使用CSS变量定义颜色和尺寸，可以通过修改 `style.css` 文件中的变量值来自定义皮肤：

```css
:root {
  /* 主色调 */
  --forest-primary: #A3E635;
  
  /* 背景色 */
  --forest-bg-primary: #FAFAFA;
  
  /* 文字色 */
  --forest-text-primary: #333333;
  
  /* 边框色 */
  --forest-border-primary: #E5E7EB;
  
  /* 圆角大小 */
  --forest-radius-sm: 6px;
  --forest-radius-md: 8px;
  --forest-radius-lg: 12px;
  
  /* 阴影 */
  --forest-shadow-sm: 0 1px 3px rgba(0, 0, 0, 0.05);
  --forest-shadow-md: 0 4px 12px rgba(0, 0, 0, 0.08);
  --forest-shadow-lg: 0 8px 24px rgba(0, 0, 0, 0.12);
}
```
