# 魔兽争霸3皮肤设计指南

## 1. 皮肤概述

### 1.1 设计理念
魔兽争霸3皮肤采用了游戏经典的深蓝色与金色配色方案，旨在还原游戏界面的史诗感与魔幻风格。皮肤通过多层次的深色背景、金色点缀和微妙的渐变效果，营造出浓郁的奇幻游戏氛围，同时保持了现代UI的清晰度和可用性。

### 1.2 核心特点
- **主题色调**：深蓝色作为主色调，象征联盟的庄严与稳重
- **辅助色彩**：金色作为点缀，增添荣耀与权力感
- **背景系统**：多层次的蓝色背景，创造深度感和层次感
- **边框与阴影**：精细的边框和阴影设计，增强界面的立体感
- **交互反馈**：精心设计的悬停和点击效果，提供清晰的用户反馈

## 2. CSS变量系统

### 2.1 变量命名规范

魔兽皮肤严格遵循以`--color-`为前缀的CSS变量命名规范，变量名结构为`--color-<类型>-<变体>-<组件>`，确保命名的一致性和可读性。

### 2.2 核心颜色变量

```css
/* 基础色板 - 魔兽争霸3经典配色：深蓝色与金色 */
--color-primary: #1a4c82;      /* 主色调：深蓝色 - 联盟风格 */
--color-secondary: #d4af37;    /* 辅助色：金色 - 荣耀与权力 */
--theme-color: var(--color-primary); /* 兼容性变量，必须与主色调保持一致 */
--color-success: #2e7d32;      /* 成功色：深绿色 - 自然/生命 */
--color-danger: #b71c1c;       /* 危险色：深红色 - 部落/警告 */
--color-warning: #ff8f00;      /* 警告色：橙色 - 火焰/力量 */
--color-info: #01579b;         /* 信息色：蓝色 - 魔法/智慧 */
```

### 2.3 背景色系统

背景系统采用了渐变的蓝色调，从深蓝到浅蓝形成层次感：

```css
/* 背景色系统 */
--color-bg-primary: #0a1929;   /* 主背景：深海蓝 - 夜空/深海 */
--color-bg-secondary: #112740; /* 次要背景：中蓝色 - 板岩/护甲 */
--color-bg-tertiary: #1a3a5f;  /* 第三背景：浅蓝色 - 浅甲/面板 */
--color-bg-elevated: #203f60;  /* 悬浮元素背景 - 提高层次 */
--color-bg-selected: #2a5c8b;  /* 选中状态背景 - 强调 */
```

### 2.4 文本颜色系统

文本系统以白色为主，配合不同深浅的灰色，确保在深色背景上的良好可读性：

```css
/* 文本颜色系统 */
--color-text-primary: #ffffff; /* 主要文本：白色 */
--color-text-secondary: #b8c2cc; /* 次要文本：浅灰色 */
--color-text-heading: #ffffff; /* 标题文本：白色，与深蓝色背景形成高对比度 */
--color-text-muted: #718096;   /* 禁用文本：中灰色 */
--color-text-disabled: #4a5568; /* 不可用文本：深灰色 */
--color-text-inverted: #0a1929; /* 反色文本 */
```

### 2.5 边框颜色系统

边框系统以深蓝色为主，配合金色作为强调：

```css
/* 边框颜色系统 */
--color-border: #2a5c8b;       /* 边框色：深蓝色边框 */
--color-border-light: #376c9e; /* 浅色边框 */
--color-border-dark: #0f3254;  /* 深色边框 */
--color-border-accent: var(--color-secondary); /* 金色强调边框 */
--color-border-hover: #4a7db8; /* 悬浮状态边框 */
```

### 2.6 组件专用变量

## 3. 组件样式实现

### 3.1 按钮组件

按钮设计融合了金属质感和渐变效果，通过微妙的光效和阴影增强立体感：

- **基础样式**：使用`var(--color-bg-secondary)`作为默认背景色
- **变体**：提供primary、secondary、success、danger、warning、info等6种变体
- **交互效果**：
  - 悬停时边框变为金色，背景色变浅
  - 点击时有轻微下沉效果
  - 鼠标悬停时添加光效动画

### 3.2 表单元素

表单元素采用深色背景和浅色调边框，聚焦时边框变为金色并添加发光效果：

- **输入框**：使用`var(--color-bg-input)`作为背景色，聚焦时有明显视觉反馈
- **下拉菜单**：自定义下拉图标，使用金色线条
- **文本域**：支持垂直调整大小，保持与输入框一致的风格

### 3.3 表格组件

表格采用深色背景，表头使用主色调，行悬停时有背景色变化：

- **表头**：深蓝色背景，白色文字，底部有金色边框
- **行**：鼠标悬停时背景色变为浅蓝色
- **边框**：使用深色边框分隔行和列

### 3.4 卡片组件

卡片设计具有微妙的边框和阴影，顶部添加金色渐变线条增强质感：

- **基础样式**：使用次要背景色，添加边框和阴影
- **视觉增强**：卡片顶部添加渐变边框效果
- **交互效果**：鼠标悬停时轻微提升阴影

- **按钮光效**：悬停时的流光效果
- **进度条**：平滑的闪烁动画
- **导航链接**：底部线条的展开动画
- **标签页**：激活状态的下划线效果

### 4.3 滚动条自定义

自定义滚动条样式，保持与整体主题的一致性：

```css
/* 滚动条样式 - 匹配主题 */
::-webkit-scrollbar {
  width: 8px;
  height: 8px;
}

::-webkit-scrollbar-track {
  background: var(--color-bg-secondary);
}

::-webkit-scrollbar-thumb {
  background: var(--color-border);
  border-radius: var(--color-radius-sm);
}

::-webkit-scrollbar-thumb:hover {
  background: var(--color-secondary);
}
```

### 4.4 选中文本样式

自定义选中文本的背景色为金色，文字颜色为深色，增强品牌识别度：

```css
/* 选中文本样式 */
::selection {
  background: var(--color-secondary);
  color: var(--color-text-inverted);
}

::-moz-selection {
  background: var(--color-secondary);
  color: var(--color-text-inverted);
}
```

## 5. 皮肤配置文件说明

### 5.1 skin.json 文件结构

`skin.json`文件包含以下关键配置：

- **name**: 皮肤名称，显示为"Warcraft 3"
- **description**: 皮肤描述，简要说明皮肤风格和特点
- **previewColor**: 预览色，用于在皮肤选择器中显示
- **variables**: 所有CSS变量的定义，便于系统读取和应用

### 5.2 变量同步机制

- `style.css`和`skin.json`中的变量必须保持同步
- 新增变量时，需要同时在两个文件中添加
- 变量值修改时，需要在两个文件中同时更新

## 6. 开发最佳实践

### 6.1 变量使用规范

- 始终使用CSS变量，避免直接硬编码颜色值
- 组件样式定义时，优先使用对应的组件专用变量
- 确保变量命名符合`--color-<类型>-<变体>-<组件>`规范

### 6.2 样式覆盖原则

- 新增组件时，先定义专用变量，再实现具体样式
- 样式覆盖时，尽量复用现有变量，减少新变量的创建
- 保持样式的模块化和可维护性

### 6.3 响应式设计考虑

- 使用相对单位(rem, em, %)而非固定像素
- 考虑不同屏幕尺寸下的组件布局
- 针对移动设备优化交互元素大小和间距

### 6.4 性能优化

- 避免过多的嵌套选择器
- 优化动画性能，使用transform和opacity
- 合理使用CSS变量，避免变量过多导致的性能问题

### 7.1 金属质感实现

通过以下技术实现魔兽争霸3特有的金属质感：

- 多层次的边框和阴影
- 微妙的渐变效果
- 光泽效果和高光

### 7.2 色彩心理学应用

- **深蓝色**：传达信任、稳定和权威感，符合联盟的形象

- **绿色**：象征成功和自然，用于确认和完成操作
