# 赛博都市皮肤

## 概述
赛博都市皮肤是一套未来科技风格的主题设计，灵感来源于赛博朋克文化和未来都市的霓虹灯光。这套皮肤将现代科技感与未来主义美学相结合，创造出充满活力和科技感的视觉体验。

## 设计理念
赛博都市皮肤以霓虹灯光、数字雨和全息投影为视觉核心，通过明亮的对比色和科技感十足的特效，营造出未来都市的繁华景象。设计上强调：
- **科技感**：使用霓虹灯效果和数字元素，增强科技氛围
- **未来感**：采用电光蓝、霓虹紫等未来感色彩
- **动态效果**：添加数据扫描线、全息投影等动态特效
- **对比强烈**：通过明暗对比和色彩对比，突出关键信息

## 颜色方案
- **主色调**：霓虹紫 (#9d4edd) - 代表未来科技的神秘感
- **辅助色**：电光蓝 (#00f5ff) - 象征数字世界的能量
- **强调色**：荧光绿 (#00ff88) - 增强视觉冲击力
- **背景色**：深空黑 (#0a0e27) - 营造未来都市的夜景
- **文本色**：高亮白 (#ffffff) - 确保在深色背景上的可读性

## 组件特性
- **霓虹灯效果**：按钮和卡片带有霓虹灯光效果
- **数据扫描线**：背景和组件添加数据扫描线动画
- **数字雨效果**：页面背景带有数字雨特效
- **全息投影**：卡片和提示框带有全息投影效果
- **高对比度**：确保在深色背景上的高可读性

## 使用方法
1. 将皮肤文件夹放置在 `skins/` 目录下
2. 在HTML文件中引入样式文件：
   ```html
   <link rel="stylesheet" href="skins/cyber_city/style.css">
   ```
3. 添加皮肤配置：
   ```javascript
   const skinConfig = {
     name: 'cyber_city',
     path: 'skins/cyber_city/'
   };
   ```
4. 初始化皮肤：
   ```javascript
   initSkin(skinConfig);
   ```

## 特效说明
- **霓虹灯效果**：通过CSS的box-shadow和text-shadow实现
- **数据扫描线**：使用CSS动画创建横向扫描线效果
- **数字雨**：使用JavaScript和Canvas创建动态数字雨背景
- **全息投影**：使用CSS的transform和opacity实现投影效果

## 自定义选项
可以通过修改 `skin.json` 文件中的CSS变量来自定义颜色方案：
```json
{
  "cssVariables": {
    "--color-primary": "#9d4edd",
    "--color-secondary": "#00f5ff",
    "--color-accent": "#00ff88"
  }
}
```
