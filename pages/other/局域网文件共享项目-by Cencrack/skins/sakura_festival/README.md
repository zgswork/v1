# 樱花祭典皮肤

## 概述
樱花祭典皮肤是一套日式和风风格的主题设计，灵感来源于日本樱花季节的美丽景象和传统和风美学。这套皮肤将樱花的柔美与和风的雅致相结合，创造出充满东方韵味的视觉体验。

## 设计理念
樱花祭典皮肤以樱花粉、和风蓝和和纸白为色彩核心，通过柔和的色调和优雅的纹理，营造出樱花祭典的浪漫氛围。设计上强调：
- **和风美学**：使用樱花元素和和风纹理，增强东方韵味
- **柔美感**：采用樱花粉、和风蓝等柔和色彩
- **雅致感**：通过和纸白等色彩，表现和风的简约与雅致
- **和谐统一**：色彩搭配和谐，营造出宁静优雅的视觉体验

## 颜色方案
- **主色调**：樱花粉 (#ffb3c6) - 代表樱花的柔美与浪漫
- **辅助色**：和风蓝 (#8d99ae) - 象征和风的沉静与雅致
- **强调色**：和纸白 (#f1f1f1) - 表现和风的简约与纯净
- **背景色**：浅米色 (#f8f5f2) - 营造温暖舒适的背景
- **文本色**：深墨黑 (#2d3436) - 确保在浅色背景上的可读性

## 组件特性
- **樱花飘落效果**：背景和组件带有樱花飘落动画
- **和风纹样效果**：按钮和卡片带有和风纹样装饰
- **和风扇形效果**：页面元素带有和风扇形设计元素
- **柔和阴影**：组件使用柔和的阴影效果，增强立体感
- **优雅过渡**：色彩和效果过渡自然，营造和谐感

## 使用方法
1. 将皮肤文件夹放置在 `skins/` 目录下
2. 在HTML文件中引入样式文件：
   ```html
   <link rel="stylesheet" href="skins/sakura_festival/style.css">
   ```
3. 添加皮肤配置：
   ```javascript
   const skinConfig = {
     name: 'sakura_festival',
     path: 'skins/sakura_festival/'
   };
   ```
4. 初始化皮肤：
   ```javascript
   initSkin(skinConfig);
   ```

## 特效说明
- **樱花飘落效果**：通过CSS动画和JavaScript实现樱花飘落动画
- **和风纹样效果**：使用CSS的background和pattern实现和风纹样
- **和风扇形效果**：使用CSS的transform和clip-path实现扇形设计
- **柔和阴影**：使用CSS的box-shadow和text-shadow实现柔和阴影

## 自定义选项
可以通过修改 `skin.json` 文件中的CSS变量来自定义颜色方案：
```json
{
  "cssVariables": {
    "--color-primary": "#ffb3c6",
    "--color-secondary": "#8d99ae",
    "--color-accent": "#f1f1f1"
  }
}
```
