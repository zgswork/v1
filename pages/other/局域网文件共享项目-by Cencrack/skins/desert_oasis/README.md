# 沙漠绿洲皮肤

## 概述
沙漠绿洲皮肤是一套沙漠风情风格的主题设计，灵感来源于广袤沙漠中的绿洲和沙漠文化的独特美感。这套皮肤将沙漠的自然色彩与绿洲的生命力相结合，创造出温暖而富有生机的视觉体验。

## 设计理念
沙漠绿洲皮肤以沙漠金、沙棕色和绿洲绿为色彩核心，通过温暖的色调和自然的纹理，营造出沙漠中的绿洲景象。设计上强调：
- **自然感**：使用沙漠色调和自然纹理，增强自然氛围
- **温暖感**：采用沙漠金、沙棕色等温暖色彩
- **生机感**：通过绿洲绿等色彩，表现沙漠中的生命力
- **和谐统一**：色彩搭配和谐，营造出宁静舒适的视觉体验

## 颜色方案
- **主色调**：沙漠金 (#d4a574) - 代表沙漠的温暖与广阔
- **辅助色**：沙棕色 (#e4b884) - 象征沙漠的细腻与柔和
- **强调色**：绿洲绿 (#7fb069) - 表现沙漠中的生命力
- **背景色**：沙漠米 (#f5e6d3) - 营造温暖舒适的背景
- **文本色**：深棕黑 (#3e2723) - 确保在浅色背景上的可读性

## 组件特性
- **沙漠波浪效果**：背景和组件带有沙漠波浪纹理
- **绿洲水波效果**：按钮和卡片带有水波纹动画
- **沙粒纹理**：页面背景带有沙粒纹理效果
- **温暖阴影**：组件使用温暖的阴影效果，增强立体感
- **自然过渡**：色彩和效果过渡自然，营造和谐感

## 使用方法
1. 将皮肤文件夹放置在 `skins/` 目录下
2. 在HTML文件中引入样式文件：
   ```html
   <link rel="stylesheet" href="skins/desert_oasis/style.css">
   ```
3. 添加皮肤配置：
   ```javascript
   const skinConfig = {
     name: 'desert_oasis',
     path: 'skins/desert_oasis/'
   };
   ```
4. 初始化皮肤：
   ```javascript
   initSkin(skinConfig);
   ```

## 特效说明
- **沙漠波浪效果**：通过CSS的background和animation实现波浪纹理
- **绿洲水波效果**：使用CSS动画创建水波纹扩散效果
- **沙粒纹理**：使用CSS的noise滤镜和多重背景实现沙粒效果
- **温暖阴影**：使用CSS的box-shadow和text-shadow实现温暖阴影

## 自定义选项
可以通过修改 `skin.json` 文件中的CSS变量来自定义颜色方案：
```json
{
  "cssVariables": {
    "--color-primary": "#d4a574",
    "--color-secondary": "#e4b884",
    "--color-accent": "#7fb069"
  }
}
```
