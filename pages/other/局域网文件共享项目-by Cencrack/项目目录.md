# 项目目录

## 项目概述
这是一个功能完善的文件分享系统，支持文件分类管理、上传、下载和分享功能，并提供了丰富的皮肤主题切换功能。系统采用PHP开发，使用SQLite数据库存储数据，具有直观的用户界面和强大的后台管理功能。

## 目录结构

### 根目录
- `index.php` - 主页，展示文件分类和文件列表，支持文件浏览、上传、下载和预览功能
- `init_category_sort.php` - 初始化分类排序脚本，用于设置分类的默认排序
- `skin_config.json` - 皮肤配置文件，存储用户选择的皮肤信息
- `skin_loader.php` - 皮肤加载器，提供统一的皮肤加载机制，确保样式统一且不影响布局
- `skin_manager.php` - 皮肤管理页面，提供皮肤预览和切换功能
- `skin_preview.php` - 皮肤预览页面，支持实时预览和切换不同皮肤主题
- `skin_selector.php` - 皮肤选择器组件，可集成到其他页面
- `skin_switcher.php` - 皮肤切换处理器，处理皮肤切换请求并保存用户选择
- `ui_config.json` - UI配置文件，存储界面设置
- `ui_config_loader.php` - UI配置加载器，加载界面设置
- `shared/` - 共享文件目录（当前为空，用于未来扩展）
- `分享文件/` - 用户上传的文件存储目录，按分类组织
- `css/` - CSS样式目录
  - `font-awesome/` - Font Awesome字体图标库
- `skins/` - 皮肤主题目录，包含各种风格的皮肤
- `项目介绍.md` - 项目介绍文档，详细说明项目功能、特性和技术架构
- `项目目录.md` - 本项目目录说明文件，详细说明项目结构和文件功能
- `皮肤提示.md` - 皮肤使用说明文档
- `页面皮肤不一致解决.md` - 皮肤问题解决方案文档
- `数据库连接修复总结.md` - 数据库连接问题修复总结文档，记录问题原因、解决方案和测试结果

## 数据库表结构

### category_sort 表
- `id` - 主键，自增
- `category_name` - 分类名称
- `sort_order` - 排序顺序

### page_permissions 表
- `id` - 主键，自增
- `page_name` - 页面名称（文件名）
- `role` - 角色名称（admin、user、member）
- `can_access` - 是否可以访问（1为可以，0为不可以）

### shared_files 表
- `id` - 主键，自增
- `file_md5` - 文件MD5值，用于唯一标识文件
- `file_name` - 文件名
- `file_path` - 文件路径
- `file_size` - 文件大小
- `category` - 文件所属分类
- `upload_time` - 上传时间
- `download_count` - 下载次数
- `file_remark` - 文件备注

### users 表
- `id` - 主键，自增
- `username` - 用户名
- `password` - 密码（哈希值）
- `nickname` - 用户昵称
- `role` - 用户角色（admin、user、member）
- `created_at` - 创建时间
- `last_login` - 最后登录时间

## 功能说明

### 前台功能
1. **文件浏览** - 按分类浏览文件，支持多种排序方式
2. **文件上传** - 上传文件到指定分类，支持多种文件类型
3. **文件下载** - 下载文件，支持下载计数
4. **文件预览** - 在线预览文件
5. **皮肤切换** - 支持多种主题皮肤切换，包括中国风、赛博朋克、龙之谷、暗黑破坏神、鸿蒙4.0、鸿蒙6.0、魔兽争霸3、森系微光、极光幻彩、深海秘境、赛博都市、沙漠绿洲、樱花祭典、剑影侠魂和奇迹MU主题

### 后台功能
1. **用户管理**
   - 用户登录 - 安全的用户认证系统，支持密码哈希和会话管理
   - 用户权限管理 - 基于角色的访问控制（RBAC），支持admin、user、member三种角色
   - 密码重置 - 安全的密码修改功能，包含当前密码验证和CSRF保护

2. **分类管理**
   - 添加分类 - 创建新的文件分类，同时在文件系统和数据库中创建记录
   - 重命名分类 - 修改分类名称，同时更新文件夹名称
   - 删除分类 - 删除分类及其关联文件
   - 分类排序 - 拖拽调整分类显示顺序

3. **文件管理**
   - 安全文件上传 - 使用白名单验证文件类型，检查文件内容安全性
   - 安全文件浏览 - 防止目录遍历攻击，仅允许访问指定目录
   - 安全文件下载 - 验证文件类型和权限，防止敏感文件泄露
   - 安全文件删除 - 验证操作权限，防止删除系统关键文件
   - 文件扫描 - 扫描并添加文件到数据库（支持自动更新文件路径和分类）
   - 文件批量分类 - 批量修改文件分类

4. **系统设置**
   - 配置系统参数
   - 查看系统信息和数据库内容
   - 数据库备份 - 创建数据库完整备份，包含所有表结构和数据

5. **皮肤管理**
   - 皮肤预览 - 实时预览不同皮肤主题效果
   - 皮肤切换 - 动态切换界面皮肤，支持多种主题风格
   - 皮肤检查 - 检查和列出所有可用皮肤
   - 皮肤对比 - 直观展示不同皮肤的视觉差异

6. **安全管理**
   - 路径验证 - 防止目录遍历和路径注入攻击
   - 文件类型白名单 - 严格控制允许上传的文件类型
   - 文件内容检查 - 检测文件中的恶意代码和脚本
   - 文件大小限制 - 防止大文件攻击和资源耗尽
   - 操作权限验证 - 确保只有授权用户才能执行文件操作
   - 数据库文件保护 - 通过.htaccess和PHP脚本多层保护，防止直接访问数据库文件
   - CSRF防护 - 关键操作使用CSRF令牌验证
