### 4. CSS变量回退机制设计原则
- **多层回退**：每个CSS变量都设置多层回退值，确保在任何情况下都有合适的样式
- **语义化命名**：变量名清晰表达用途，如`--color-bg-card, var(--color-bg-secondary, #1a1a2e)`
- **组件专用变量**：为特定组件定义专用变量，如`--button-primary-bg, var(--color-primary, #4a148c)`
- **响应式变量**：根据屏幕尺寸和设备特性调整变量值
- **主题变量组**：将相关变量组织成组，便于整体主题切换
- **动态变量**：支持通过JavaScript动态修改变量值，实现实时主题切换

### 5. CSS变量回退实现示例
```css
:root {
  /* 主色调 - 多层回退机制 */
  --color-primary: var(--user-color-primary, #6200ea);
  --color-secondary: var(--user-color-secondary, #03dac6);
  --color-accent: var(--user-color-accent, #ff0266);
  
  /* 背景色 - 组件专用回退 */
  --color-bg-primary: var(--color-bg-dark, #0a0a0f);
  --color-bg-secondary: var(--color-bg-medium, #1a1a2e);
  --color-bg-tertiary: var(--color-bg-light, #16213e);
  
  /* 组件专用变量 - 带多层回退 */
  --button-primary-bg: var(--color-primary, var(--color-accent, #6200ea));
  --button-primary-text: var(--color-text-on-primary, #ffffff);
  --card-bg: var(--color-bg-card, var(--color-bg-secondary, #1a1a2e));
  --card-border: var(--color-border-card, var(--color-border, #2a2a3e));
  
  /* 文本色 - 带对比度回退 */
  --color-text-primary: var(--color-text-light, #e0e0ff);
  --color-text-secondary: var(--color-text-medium, #b0b0cc);
  --color-text-muted: var(--color-text-dark, #8080aa);
  
  /* 特效变量 - 带兼容性回退 */
  --shadow-glow: 0 0 20px var(--color-primary, #6200ea);
  --transition-smooth: var(--transition-duration, 0.3s) var(--transition-easing, ease);
  --border-radius-card: var(--radius-lg, var(--radius-md, 8px));
}
```

### 6. 组件样式实现要求
- **按钮组件**：使用`var(--button-primary-bg, var(--color-primary, #6200ea))`确保按钮背景色始终有合适值
- **卡片组件**：使用`var(--card-bg, var(--color-bg-secondary, #1a1a2e))`确保卡片背景在任何情况下都可见
- **表单组件**：使用`var(--input-bg, var(--color-bg-tertiary, #16213e))`确保输入框背景与主题协调
- **文本组件**：使用`var(--color-text-primary, var(--color-text-light, #e0e0ff))`确保文本在任何背景下都清晰可读

## CSS实现要求

### 1. 使用CSS属性选择器
- 使用属性选择器（如`[class*="btn-"]`）来选择具有特定类名的元素
- 避免过度使用类选择器，提高选择器的灵活性和可维护性
- 使用属性选择器实现组件的变体样式（如`[class*="btn-primary"]`）

### 2. CSS变量定义
- 定义全局CSS变量来存储颜色、尺寸、间距等设计令牌
- 使用有意义的变量命名，如`--color-primary`、`--size-border-radius`等
- 确保变量命名的一致性和可读性

### 3. 响应式设计
- 使用媒体查询实现响应式布局
- 确保在不同屏幕尺寸下的良好显示效果
- 考虑移动设备的交互方式

### 4. 动画与过渡效果
- 为交互元素添加适当的过渡效果
- 使用CSS动画实现加载、提示等动态效果
- 确保动画流畅且不影响性能

### 5. 浏览器兼容性
- 确保样式在主流浏览器中的兼容性
- 使用适当的前缀和回退方案
- 考虑渐进增强的设计理念
